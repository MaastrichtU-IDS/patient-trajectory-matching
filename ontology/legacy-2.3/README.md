# Historical, non-normative ontology drafts

These files are preserved only to explain v2.0–v2.3 artifacts. They include specialized properties and literal encodings that have been superseded by the PRO/SOLID contract in v2.4.

Do not import or use these files to generate current instance data. Use `../pro-solid-profile.ttl`, `../pro-solid-shapes.ttl` and `../../examples/pro-solid/graph.ttl`. Existing flat matcher JSON is a DTO representation, not an ontology vocabulary.
