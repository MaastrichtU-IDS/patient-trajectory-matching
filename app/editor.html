01 · SOURCE + RELATION

Edit the temporal question

Allen relations describe both intervals. Before and after are strict; meets means touching endpoints. A signed gap measures collection start minus infusion end and uses inclusive bounds.

02 · OPTIONAL CONJUNCTS

Constrain duration and overlap

Use ordinary decimal minutes, up to six fractional digits. Signed gaps: −1440 to 1440. Duration: greater than 0 to 1440. Shared time: greater than 0 to 1440. Conflicting constraints can yield no match.
